# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Overview

Personal dotfiles for macOS/Linux development environments. The repo contains shell, editor, git, and tool configurations that are symlinked into `$HOME` via `bootstrap.sh`.

## Architecture

- **`bootstrap.sh`** — Installation script that:
  1. Backs up existing dotfiles to `~/dotfiles-backup/`
  2. Symlinks config files (`vimrc`, `zshrc`, `gitconfig`, `gitignore_global`, `p10k.zsh`) as `~/.<name>`
  3. Installs Powerlevel10k theme and MesloLGS NF fonts
  4. Symlinks `claude/settings.json` to `~/.claude/settings.json`
  5. Copies `claude/CLAUDE.md` to `~/CLAUDE.md` (global Claude Code context for all projects)
  6. On Spin environments (`$SPIN`): also installs Oh-My-Zsh, vim-plug, and Vim plugins
- **`claude/CLAUDE.md`** — Global project context file applied to all repos (not this repo specifically)
- **`claude/settings.json`** — Claude Code permissions and environment settings

## Key Commands

```bash
# Install/update all dotfiles (symlinks + dependencies)
./bootstrap.sh

# After editing zshrc, reload without restarting terminal
source ~/.zshrc

# After editing vimrc, install new plugins
vim +PlugInstall +qall
```

## Editing Guidelines

- Config files live at the repo root (no dot prefix) and get symlinked as dotfiles (e.g., `zshrc` → `~/.zshrc`)
- `zshrc` is organized into clearly labeled `#===` sections by category — add new config to the appropriate section
- `vimrc` follows the same section pattern — plugins go in the `plug#begin/end` block, settings go in the matching section
- `gitconfig` uses `[alias]` for shortcuts and has Graphite (`gt`) integration via `stack`/`submit` aliases
- `p10k.zsh` is generated by `p10k configure` — edit manually only for fine-tuning, not wholesale changes

## Code Style

- 2-space indentation for all config files (shell, vim, git, JSON, YAML)
- 4-space indentation for Swift; tabs for Go (in vimrc `autocmd` settings)
- Use trailing commas in multi-line arrays/objects
- Prefer Nix packages over Homebrew; Bun over Node for new JS projects; pnpm/yarn over npm

## Git Workflow

- Uses **Graphite** (`gt`) for stacked PRs
- Default branch: `main`
- Diff tool: Kaleidoscope
- Pull is configured to rebase by default (`branch.autosetuprebase = always`)
